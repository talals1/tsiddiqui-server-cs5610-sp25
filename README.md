# Kambaz Backend Server
Spring 2025

Course-long iterative homework for CS5610: Web Development at Northeastern University.

This is essentially a backend clone of Canvas, a popular learning management system, but built on Node. This backend uses Node, Express, Express Session, Mongoose, and CORS. MongoDB is used for the database.

## Running
Please ensure the database is running either locally or on MongoDB Atlas.

To run the backend, first run `npm install` then `nodemon index.js`.
